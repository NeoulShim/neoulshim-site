설치부터 사용까지 안내 →

결과는 이 브라우저에 자동 보관되며 서버로 전송되지 않습니다. 시크릿 창은 닫으면 기록이 지워질 수 있으니 결과 파일 저장으로 보관해 주세요. 내려받은 파일을 기획·개발 담당자에게 전달하면 됩니다.

1. 설치와 메뉴

새 테스트 Docs에 설치 후 새로고침. 원고 미리보기와 문서 옆 뷰어 메뉴가 보인다.

2. 다섯 장면 읽기

예시 원고를 붙여넣고 현재 Docs 읽기. 본문 다섯 씬과 서윤·도현·정숙의 대사가 누락 없이 보인다.

3. 탭형 인물명 배치

탭형에서 서윤·도현·정숙의 이름과 대사 시작 위치가 일정하게 유지된다.

4. 큰 원고 화면

화면 너비 맞춤·100%·200%와 원고만 크게 보기, 설정 다시 보기를 확인한다.

5. 양식과 글꼴

글꼴·용지·여백·대사 배치를 바꿔 적용한다. 미리보기와 출력에 선택한 설정이 반영된다.

6. 기본값 복원

내 기본 설정 저장됨 확인 후 뷰어를 닫고 다시 열어 원고를 읽는다. 적용한 설정이 유지된다.

7. 자동 갱신

Docs에서 대사를 수정한다. 자동 갱신을 켜면 약 15초+처리시간 후 반영되고 끄면 수동 읽기 전까지 유지된다.

8. 문서 옆 뷰어

Docs에서 계속 편집할 수 있고 옆 뷰어에서 최신 원고를 읽을 수 있다.

9. 버전 저장·비교

이름 있는 버전을 저장한 뒤 원고를 수정·갱신한다. 추가·삭제된 대사와 양식 변경을 비교할 수 있다.

10. 과거 버전 보호

과거 버전을 미리 보는 동안 자동 갱신이 덮어쓰지 않는다. 현재 원고로 돌아가면 최신 원고가 유지된다.

11. 기록 파일 다시 열기

기록 파일을 내려받고 뷰어를 다시 연 뒤 같은 문서에서 가져온다. 과거 버전과 양식이 보존된다.

12. HWPX 파일

HWPX를 내려받아 한글에서 연다. 긴 이름·대사 누락, 겹침, 불필요한 빈 쪽을 확인한다.

13. PDF 파일

PDF 저장/인쇄에서 PDF로 저장한다. 글꼴·쪽 나눔·긴 이름이 미리보기와 합리적으로 일치하는지 확인한다.

14. 원본 보존

출력·버전 비교·양식 변경 후 Docs 원고와 공동 편집 내용이 덮어써지지 않았는지 확인한다.

자동 테스트 48개·로컬 화면 검사를 통과한 개발판입니다. 실사용 환경의 한글 렌더링과 브라우저 다운로드 차이를 확인하기 위한 QA이며, Marketplace 정식 배포판은 아닙니다.
