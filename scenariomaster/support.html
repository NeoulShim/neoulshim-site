사용 도움말 및 문의

쓰던 문서에서 바로 열기 · 1.2.0

시나리오의 거장 → Docs 안에서 열기를 누르면 현재 원고가 바로 보입니다. 처음 한 번 자동 갱신 연결에서 지금 Docs를 쓰는 Google 계정을 승인하세요. 파일을 다시 고르지 않습니다.

글의 추가·수정·삭제는 자동 반영되며, 창을 다시 열어도 연결을 최대 30일 유지합니다. 여러 계정이 로그인된 Chrome에서도 시험했습니다. 이미지는 창을 열 때의 모습으로 출력됩니다. 이미지를 추가·교체한 뒤에는 창을 닫고 다시 열어 주세요. 원고와 이미지를 연결 서버에 보내지 않습니다.

Google Marketplace 정식 승인은 아직 완료되지 않았습니다. QA 참여자는 공유받은 테스트 문서의 사본으로 시작하세요.

처음 시작하기

정식 Marketplace 등록을 준비 중입니다. 현재 제공되는 개발판의 설치 과정은 설치 안내에서 확인할 수 있습니다. 정식 설치 링크는 심사 승인 후 공개합니다.

설치한 뒤 Google Docs에서 확장 프로그램 → 시나리오의 거장 → Docs 안에서 열기를 실행합니다. 원고를 읽으면 양식을 선택하고 글꼴·용지·여백 등을 바꿀 수 있습니다. HWPX는 다운로드 버튼으로, PDF는 인쇄 화면에서 PDF 저장을 선택해 내보냅니다.

원고 작성

씬은 #씬 제목, 인물은 @인물명 다음 줄에 대사를 적습니다. 지문은 빈 줄로 구분한 일반 문단으로 작성합니다. 문서에 삽입한 이미지도 함께 읽습니다. 상세 문법과 이미지 안내를 확인해 주세요.

자동 갱신 중 권한 오류가 나나요?

예전 Docs 내부 창은 여러 Google 계정이 로그인되어 있을 때 연결 오류가 날 수 있었습니다. 1.1.0에서는 계정과 원고를 직접 선택하는 연결 방식으로 바꿨습니다.

  1. 위의 원고 연결하고 미리보기를 누르세요.
  2. 원고가 있는 Google 계정을 선택하고 Google 파일 선택창에서 원고를 선택하세요.
  3. 이 창을 문서 옆에 두면 수정 사항을 자동으로 읽습니다. 다른 계정을 로그아웃하거나 새 프로필을 만들 필요가 없습니다.

연결은 창이 열려 있는 동안 최대 24시간 유지됩니다. 만료되거나 접근 권한을 철회했다면 다시 연결을 누르세요. 조직의 앱 차단이나 문서 자체의 접근 제한이 있다면 해당 안내 문구를 확인해 주세요. 연결 오류 중에는 마지막으로 읽은 원고가 보이므로 출력 전 최신 내용인지 확인하세요.

문제가 생겼을 때

  • 최신 내용이 보이지 않으면 Docs의 저장 완료를 확인하고 Docs 최신 내용 읽기를 누르세요. 연결이 만료되었다면 다시 연결에서 계정과 원고를 선택하세요.
  • 연결 오류가 반복되면 해당 문서에 접근할 수 있는 Google 계정인지 확인하세요. 새 연결 화면에서는 여러 계정이 동시에 로그인되어 있어도 사용할 수 있습니다.
  • 이미지 읽기에 실패하면 이미지 크기를 줄이거나 본문 안에 배치한 뒤 다시 여세요.
  • 파일 다운로드는 브라우저 다운로드 목록을 확인하세요. PDF 저장은 인쇄 창에서 완료해야 합니다.
  • 함초롱바탕 등 선택한 글꼴이 기기에 없으면 대체 글꼴로 표시될 수 있습니다.

오류를 알려 주세요

어떤 버튼을 눌렀는지, 오류 문구, 브라우저 이름을 알려 주시면 도움이 됩니다. 화면을 첨부할 때 원고·계정·이메일 등 개인정보는 가려 주세요. 비밀번호나 인증 코드는 보내지 마세요.

삭제하기

Google Docs의 확장 프로그램 → 부가기능 → 부가기능 관리에서 제거할 수 있습니다. 접근 권한은 Google 계정 연결 관리에서 철회할 수 있습니다. 자세한 데이터 안내는 개인정보처리방침을 확인하세요.
