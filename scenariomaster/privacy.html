원고를 어떻게 처리하나요?

시나리오의 거장은 사용자가 연결한 Google Docs 문서의 제목, 문서 식별자, 탭, 본문, 굵기·기울임 정보와 삽입 이미지를 읽어 미리보기와 파일 출력에 사용합니다. 사용자가 연결한 뒤에는 변경 사항을 자동으로 확인합니다. 원본 문서를 수정하거나 삭제하지 않습니다. 원고를 광고·판매·AI 모델 학습에 사용하지 않습니다.

Docs 안에서 열기와 Google 권한

  • 처음 원고 표시: documents.currentonly 권한으로 현재 열린 문서를 읽고, script.container.ui 권한으로 Docs 안에 미리보기 창을 표시합니다.
  • 자동 갱신 연결: drive.file 권한으로 Google 확인창에서 선택한 파일만 Google Docs API에서 직접 읽습니다. 처음 연결할 때 현재 원고를 확인창에 표시하며, 확인한 뒤 같은 원고를 다시 열면 연결을 유지합니다. 이 권한에는 선택한 파일의 수정·삭제도 포함되지만 앱은 읽기만 수행합니다. 계정 전체 문서를 읽는 documents.readonly 권한은 요청하지 않습니다. openid·email은 연결한 계정이 현재 Docs 계정과 같은지 확인하는 데 사용합니다.
  • 기존 문서 선택 연결: 별도 연결 화면은 drive.file 권한과 Google 파일 선택창을 사용합니다. 이 권한은 선택한 파일의 수정·삭제도 허용하지만 앱은 읽기 요청만 수행합니다.

민감한 데이터를 어떻게 보호하나요?

문서의 본문, 제목, 삽입 이미지에는 개인정보나 공개되지 않은 창작물이 포함될 수 있으므로 접근과 보관을 다음과 같이 제한합니다.

  • 원고 처리: 자동 갱신과 문서 선택 연결에서는 Google Docs API와 이미지 제공 서버에서 사용자의 브라우저로 원고를 직접 읽습니다. 기존 뷰어는 Google Apps Script와 사용자 브라우저에서 처리합니다. 운영자의 연결 서버는 원고·문서 제목·문서 식별자·이미지를 받거나 보관하지 않습니다.
  • 전송 보호: Google·브라우저·연결 서버 사이의 통신은 HTTPS를 사용합니다. 문서 읽기는 연결할 때 선택한 계정의 접근 토큰을 사용하며 Google 로그인 쿠키에 의존하지 않습니다.
  • 연결 서버: 운영자의 Cloudflare Workers 서버는 Google 인증 코드 교환과 접근 토큰 갱신만 처리합니다. 이 과정에서 인증 코드·접근 토큰·갱신 토큰을 일시적으로 처리합니다. Google 클라이언트 비밀키와 암호화 키는 Cloudflare의 비밀값 저장 기능으로 관리하며 공개 웹페이지에 포함하지 않습니다.
  • 인증 정보 보호: Docs 자동 갱신의 갱신 토큰과 계정 확인 정보는 AES-GCM으로 암호화하여 운영자의 Cloudflare KV에 최대 30일 보관합니다. 서버 비밀값으로 관리하는 키는 브라우저에 전달하지 않습니다. 브라우저에는 Secure·HttpOnly·SameSite=None·Partitioned 쿠키로 무작위 연결 식별자만 보관합니다. 접근 토큰은 창의 메모리에만 두고, 원본 갱신 토큰은 브라우저에 전달하지 않습니다. 서버는 Google이 검증한 계정과 현재 Docs 계정이 같은지 확인합니다. 요청은 neoulshim.kr 출처로 제한하고 인증 요청 본문·헤더·토큰을 앱 로그에 기록하지 않습니다.
  • 보관 최소화와 연결 해제: 원고와 이미지는 창의 메모리에서만 처리하며 운영자 데이터베이스·브라우저 영구 저장소에 저장하지 않습니다. Docs 뷰어를 닫으면 원고는 사라지고 인증 연결만 최대 30일 유지됩니다. ‘연결 안내 → 자동 갱신 연결 해제’로 Google 토큰을 폐기하고 보관한 연결을 삭제할 수 있습니다. Google에서 권한을 철회하면 다음 연결 확인 때 사용할 수 없으며, 남은 암호화 기록도 보관 기간이 지나면 자동 만료됩니다. 기존 문서 선택 연결은 암호화된 인증정보를 창의 메모리에 최대 24시간 유지하며 닫으면 사라집니다.
  • 외부 전송 제한: 원고·이미지를 광고·방문 통계·AI 서비스로 전송하지 않습니다. 문서 연결 뷰어에는 방문 통계 스크립트를 넣지 않습니다. 운영자는 원고를 조회하는 관리 화면이나 원고 보관 서버를 운영하지 않습니다.

HWPX·PDF 등 내보낸 파일은 사용자의 기기에 남으며 앱이 파일 자체를 암호화하지는 않습니다. 내려받은 파일과 원본 문서의 공유 권한은 사용자가 관리합니다. 공용 기기에서는 사용 후 뷰어를 닫고 Google 계정에서 로그아웃해 주세요.

설정과 보관 기간

양식 등 기본 설정은 브라우저 저장소와 Google Apps Script의 사용자별 속성에 저장될 수 있습니다. 이 설정에는 원고가 포함되지 않습니다. 브라우저 설정은 해당 사이트 데이터를 삭제하면 지워집니다. 계정에 저장된 설정은 이후 실행에도 남을 수 있습니다. 관련 문의는 위 연락처로 보내 주세요. 미리보기 내용은 창이 열려 있는 동안 처리하며, 사용자가 내려받은 파일은 사용자의 기기에 남습니다.

공유·지원·서비스 제공자

앱은 원고의 공유 권한을 변경하지 않습니다. Google Docs 공동 작업 권한은 사용자가 관리합니다. 문의 메일을 보내면 이메일 주소와 문의 내용이 Gmail을 통해 운영자에게 전달됩니다. 지원에 필요하지 않은 원고·개인정보는 보내지 마세요. 문의 내용은 답변과 문제 해결에 사용하며 삭제 요청은 같은 주소로 접수합니다. Google과 Cloudflare는 서비스 제공 및 보안을 위해 자체 정책에 따라 접속·서비스 정보를 처리할 수 있습니다. Cloudflare 연결 서버로는 인증 처리에 필요한 정보만 전달하며 원고를 보내지 않습니다.

홈페이지 방문 통계

소개 홈페이지에는 Cloudflare Web Analytics를 사용합니다. 이 통계는 홈페이지 방문을 파악하기 위한 것으로, 부가기능 안의 원고나 Google 문서를 통계로 전송하지 않습니다. 자세한 내용은 Cloudflare 개인정보처리방침을 참고하세요.

권한 철회

Google 계정의 서드 파티 연결에서 앱 접근 권한을 철회할 수 있습니다. 부가기능 삭제는 Google Docs의 확장 프로그램 → 부가기능 → 부가기능 관리에서 진행합니다. 원래 Google 문서와 이미 내려받은 파일은 자동 삭제되지 않습니다.

Google API 데이터 사용

시나리오의 거장이 Google API에서 받은 정보를 사용하거나 다른 앱으로 전송하는 행위는 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다. Google 사용자 데이터는 광고나 범용 AI 모델 개발·학습에 사용하지 않습니다.

중요한 변경은 이 페이지에 시행일과 함께 알립니다.
