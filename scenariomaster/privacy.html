원고를 어떻게 처리하나요?

시나리오의 거장은 사용자가 연 Google Docs 문서의 제목, 문서 식별자, 탭, 본문, 굵기·기울임 정보와 삽입 이미지를 읽어 미리보기와 파일 출력에 사용합니다. 문서 열기만으로 원고를 읽지 않으며, 사용자가 뷰어를 실행한 뒤에는 변경 사항을 자동으로 확인합니다. 원본 문서를 수정하지 않습니다.

원고는 Google의 Apps Script·Docs 서비스와 사용자 브라우저에서 처리됩니다. 운영자의 별도 서버에 원고를 보관하거나 운영자에게 전송하지 않습니다. 원고를 광고, 판매 또는 AI 모델 학습에 사용하지 않습니다.

요청하는 Google 권한

  • 현재 문서 접근: 열린 문서와 삽입 이미지 정보를 읽습니다.
  • 문서 내 사용자 인터페이스 표시: 미리보기 창과 옆 패널을 표시합니다.

현재 문서 전용 권한(documents.currentonly)을 사용합니다. 다른 문서를 검색하거나 여는 기능은 없으며, Google 접근 토큰을 브라우저에 전달하지 않습니다.

민감한 데이터를 어떻게 보호하나요?

문서의 본문, 제목, 삽입 이미지에는 개인정보나 공개되지 않은 창작물이 포함될 수 있으므로 다음과 같이 접근과 보관을 제한합니다.

  • 전송 보호: Google Docs·Apps Script와 브라우저 사이의 통신은 Google이 제공하는 HTTPS 연결을 사용합니다. 앱이 별도로 원고를 전송하는 운영자 서버는 없습니다.
  • 최소 권한: Google 계정의 승인과 현재 문서 전용 권한으로 사용자가 연 문서를 읽습니다. 계정 전체 문서 목록을 검색하거나 다른 문서를 열지 않습니다. 원고와 이미지 읽기는 사용자가 뷰어를 실행한 뒤에만 이루어집니다.
  • 인증 정보 보호: Google 접근 토큰은 뷰어에 전달하거나 브라우저 저장소에 저장하지 않습니다. 원고 읽기는 Google Apps Script의 승인된 실행 환경에서 처리합니다.
  • 보관 최소화: 미리보기 원고와 이미지는 실행 중인 창의 메모리에서 처리하며, 원고를 브라우저의 영구 저장소나 운영자의 데이터베이스에 저장하지 않습니다. 브라우저와 Apps Script 사용자별 속성에는 양식·보기 설정만 저장할 수 있습니다.
  • 외부 전송 제한: 부가기능의 원고·이미지를 광고, 방문 통계 또는 AI 서비스로 전송하지 않습니다. 운영자는 앱을 통해 사용자의 원고를 조회하는 관리 화면이나 원고 보관 서버를 운영하지 않습니다.

HWPX와 PDF 등 사용자가 내보낸 파일은 사용자의 기기에 남으며 앱이 파일 자체를 암호화하지는 않습니다. 내려받은 파일과 원본 문서의 공유 권한은 사용자가 관리해야 합니다. 공용 기기에서는 사용 후 뷰어를 닫고 Google 계정에서 로그아웃해 주세요.

설정과 보관 기간

양식 등 기본 설정은 브라우저 저장소와 Google Apps Script의 사용자별 속성에 저장될 수 있습니다. 이 설정에는 원고가 포함되지 않습니다. 브라우저 설정은 해당 사이트 데이터를 삭제하면 지워집니다. 계정에 저장된 설정은 이후 실행에도 남을 수 있습니다. 관련 문의는 위 연락처로 보내 주세요. 미리보기 내용은 창이 열려 있는 동안 처리하며, 사용자가 내려받은 파일은 사용자의 기기에 남습니다.

공유·지원·서비스 제공자

앱은 원고의 공유 권한을 변경하지 않습니다. Google Docs 공동 작업 권한은 사용자가 관리합니다. 문의 메일을 보내면 이메일 주소와 문의 내용이 Gmail을 통해 운영자에게 전달됩니다. 지원에 필요하지 않은 원고·개인정보는 보내지 마세요. 문의 내용은 답변과 문제 해결에 사용하며 삭제 요청은 같은 주소로 접수합니다. Google 플랫폼은 자체 정책에 따라 서비스·오류 로그를 처리할 수 있습니다.

홈페이지 방문 통계

소개 홈페이지에는 Cloudflare Web Analytics를 사용합니다. 이 통계는 홈페이지 방문을 파악하기 위한 것으로, 부가기능 안의 원고나 Google 문서를 통계로 전송하지 않습니다. 자세한 내용은 Cloudflare 개인정보처리방침을 참고하세요.

권한 철회

Google 계정의 서드 파티 연결에서 앱 접근 권한을 철회할 수 있습니다. 부가기능 삭제는 Google Docs의 확장 프로그램 → 부가기능 → 부가기능 관리에서 진행합니다. 원래 Google 문서와 이미 내려받은 파일은 자동 삭제되지 않습니다.

Google API 데이터 사용

시나리오의 거장이 Google API에서 받은 정보를 사용하거나 다른 앱으로 전송하는 행위는 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다. Google 사용자 데이터는 광고나 범용 AI 모델 개발·학습에 사용하지 않습니다.

중요한 변경은 이 페이지에 시행일과 함께 알립니다.
