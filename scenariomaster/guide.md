# Scenario Text v1 — Docs 원고 문법

Google Docs에서 평소처럼 원고를 쓰세요. 씬 제목과 인물 이름 앞에 간단한 기호만 붙이면 대사와 지문을 구분합니다. 글꼴·크기·굵게·기울임 같은 출력 모양은 플러그인의 양식 설정에서 정합니다.

## 바로 쓸 수 있는 예제

```text
##마지막 상영

#작은 영화관 / 밤

마지막 관객이 나간다.
서윤이 빈 객석에 앉는다.

$서윤 (V.O.)
아직 끝난 건 아니지?
한 번 더 볼 수 있을까.

영사실에서 불빛이 새어 나온다.

$도현
다시 시작할게.

> FADE OUT.

---

# S02. 영화관 앞 / 새벽
```

## 읽는 규칙

| 입력 | 의미 | 정확한 조건 |
| --- | --- | --- |
| `##큰 제목` 또는 `## 큰 제목` | 큰 제목 | 작품명·부 제목을 기본 20pt 굵게 표시합니다. 씬 번호와 별개이며 양식의 큰 제목 설정에서 조절합니다. |
| `#씬 제목` 또는 `# 씬 제목` | 씬 제목 | 공백 없이도 씬으로 인식합니다. 씬 번호나 식별자를 직접 적지 않아도 됩니다. |
| `$서윤` 또는 `$ 서윤` | 인물명 | `$` 뒤 내용 전체가 인물명입니다. 괄호·직책·음성 표기도 이름에 포함됩니다. |
| 인물명 바로 다음 일반 줄 | 대사 | 빈 줄이나 다른 종류의 지시가 나오기 전까지 대사입니다. 다음 `$`는 새 인물입니다. |
| 빈 줄 | 문단 경계 | 대사 상태를 끝냅니다. 여러 빈 줄이 같은 크기의 출력 공백을 누적하지는 않습니다. |
| 일반 텍스트 | 지문 | 대사 상태가 아닐 때의 일반 줄입니다. 연속한 일반 줄은 같은 문단 안의 줄바꿈입니다. |
| `> 전환` | 전환 | `>` 뒤 공백이 필요합니다. 오른쪽 정렬 등 출력 양식의 전환 서식을 씁니다. |
| `---` | 강제 쪽 나눔 | 다른 글자 없이 한 줄에 씁니다. 다음 내용부터 새 쪽입니다. 맨 앞·연속 사용은 빈 쪽 생성 수단으로 권장하지 않습니다. |
| `\$문자 그대로` | 문자 그대로의 지문 | 역슬래시는 줄의 첫 문자여야 합니다. 첫 역슬래시 하나만 제거하고 그 줄을 지문으로 읽습니다. |

씬·인물·전환 기호는 줄 앞쪽 공백을 제거한 뒤 판별합니다. 기호 뒤의 앞뒤 공백도 제거됩니다. 일반 지문·대사 내부 텍스트와 줄바꿈은 보존합니다. 출력 양식은 자동 줄바꿈을 추가할 수 있습니다.

괄호는 별도 문법이 아니라 원문 그대로 출력합니다. 지문을 넣으려면 대사를 빈 줄로 끝내고 일반 문장으로 쓰세요. 빈 줄 뒤에도 같은 인물이 말한다면 다시 `$서윤`을 적으세요. 대사 한 문단 안에서 단순히 줄만 바꾸려면 빈 줄 없이 Enter를 누릅니다.

`$서윤 (V.O.)`, `$서윤 (E)`, `$서윤 (계속)`은 이름에 붙인 표시를 그대로 출력합니다. 음성 표기를 따로 분석하거나 자동으로 붙이지 않습니다. `INT.`, `EXT.`, `S#1`, 대문자 인물명만으로 자동 추론하지 않습니다. 예를 들어 기존 `S#1. 방 / 낮`은 `# S#1. 방 / 낮`으로 명시하세요.

기본 굵게·기울임은 양식 설정에서 선택하세요. Docs 편집기에서 직접 적용한 굵게·기울임은 양식의 기본값보다 우선합니다. 원고에 별표나 밑줄 기호를 넣어도 글자 모양이 바뀌지는 않습니다. 두 인물의 동시 대사나 페이지 끝의 자동 ‘계속’ 표시는 아직 지원하지 않습니다.

## 이름과 문장이 길 때

- 인물명을 위에 두는 양식: 출력 폭 안에서 이름을 자동 줄바꿈합니다. 이름 전체와 다음 대사 첫 부분이 한 쪽에 들어가면 함께 배치합니다.
- 인물명 옆에 대사를 두는 양식: 이름이 지정된 인물명 폭에 여유 3mm를 더해 들어가지 않으면 해당 발화만 이름을 위에 놓고 대사를 아래에 배치합니다. 이름을 자르거나 생략하지 않습니다. 폭 판정은 공통 추정 글자 폭 기준으로, 설치 글꼴의 정확한 폭과 약간 다를 수 있습니다.
- 긴 지문: 한 문단이 여러 쪽이어도 남은 줄을 순서대로 다음 쪽에 이어 씁니다. 원고에서 인위적으로 쪽을 나눌 필요가 없습니다.
- 긴 대사: 여러 쪽으로 이어집니다. 현재는 다음 쪽에서 인물명이나 ‘계속’ 표시를 자동 반복하지 않습니다. 표기의 필요 여부는 제출·제작 양식에 따라 확인하세요.
- 원문에 직접 넣은 줄바꿈은 인물 옆 대사 양식에서도 유지됩니다. 지문과 대사는 빈 줄로 구분합니다.
- 한글과 PDF는 서로 다른 조판 엔진과 설치 글꼴을 사용합니다. 내용은 같아도 줄바꿈과 쪽 수가 다를 수 있습니다.

## 씬 번호와 이동

`#씬 제목`만 적으세요. 플러그인의 씬 목록은 문서 탭 순서와 씬 등장 순서대로 1부터 번호를 매깁니다. 씬을 추가·삭제·이동하면 다시 읽을 때 번호가 갱신됩니다. 목록에서 선택하거나 이전·다음 씬으로 이동할 수 있습니다. 출력에는 기본적으로 1. 씬 제목, 2. 씬 제목처럼 번호가 붙습니다. 양식 설정에서 자동 씬 번호를 끌 수 있으며 Docs 원문은 바뀌지 않습니다. 제목에 S01이나 연도처럼 숫자가 이미 있으면 번호를 덧붙이지 않습니다.

기존 `{#식별자}` 원고는 호환을 위해 계속 읽지만 새 원고에는 필요하지 않습니다. 번호는 순서에 따라 변하므로 버전 간 영구 식별자로 사용하지 않습니다.

## 문법 기호 변경

Docs 뷰어의 **문법과 출력 설정 → 문법 적용**은 해석할 기호만 바꾸며 Docs 원문을 고치지 않습니다. 서로 다른 팀이 다른 기호를 쓰는 경우 같은 설정을 선택하세요. 변경한 설정은 이 브라우저에 자동으로 저장됩니다. 인물명에는 달러 기호($)를 사용하세요.

기본 기호를 그대로 쓰면 별도 설정이 필요 없습니다. 팀에서 다른 기호를 쓰는 경우에만 바꾸세요. 사용할 수 없는 조합은 설정 화면에서 안내합니다.


## 이미지 넣기

Google Docs에서 **삽입 → 이미지**로 사진을 넣으면 자동으로 읽어 미리보기와 HWPX·PDF 출력에 포함합니다. 별도 문법을 입력할 필요가 없습니다. 이미지는 창을 열 때 읽으므로 추가·교체한 뒤에는 뷰어를 닫고 다시 열어 주세요.

이미지 앞뒤를 빈 줄로 구분하고 **텍스트 줄 안** 배치를 사용하세요. Docs에서 조절한 크기를 반영하며, 용지보다 크면 비율을 유지하며 줄입니다. 글 주위를 감싸거나 고정한 이미지는 연결된 문단 다음에 배치합니다. 이미지 안의 글자를 대사로 바꾸는 기능은 아닙니다.

한 문서에서 최대 40개, 변환한 이미지 전체 약 5MB까지 지원합니다. 이미지가 너무 크거나 읽기에 실패하면 안내하고 내보내기를 잠시 멈춰 누락을 방지합니다. Google 연결 문제가 계속되면 문서 메뉴에서 뷰어를 다시 열어 주세요.

## Docs에서 작성하고 출력하기

Docs의 모든 문서 탭과 하위 탭에서 원고를 읽습니다. 공동 작업자가 제안한 수정은 Docs에서 승인한 뒤 다시 읽어야 반영됩니다. 각주 등은 출력되지 않을 수 있으므로 내보내기 전에 미리보기를 확인하세요.

문서 상단의 시나리오의 거장 → Docs 안에서 열기를 누르면 현재 원고가 보입니다. 처음 한 번 자동 갱신 연결을 승인하면 글의 추가·수정·삭제가 자동으로 반영됩니다. 필요한 경우 ‘Docs 최신 내용 읽기’로 바로 확인할 수도 있습니다. 원하는 양식을 고르고 미리보기를 확인한 다음 HWPX 또는 PDF로 출력합니다. 버전 기록과 공동 작업은 Google Docs의 기능을 그대로 사용하세요.
